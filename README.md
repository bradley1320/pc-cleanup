# PC Cleanup v2

> The Windows optimizer you can read, understand, and undo — one tweak at a time.

**v2 is under active development.** See [CLAUDE.md](CLAUDE.md) for the full specification.

## Quick Start

1. Download the latest release ZIP
2. **Right-click the ZIP → Properties → check "Unblock" → OK**
3. Extract the ZIP
4. Right-click `Run.bat` → Run as Administrator
